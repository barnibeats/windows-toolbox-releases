# Windows Toolbox

A catalog of free open-source apps for Windows, with one-click downloads of the latest Windows release: personalization, gaming, administration, system tweaking, plus built-in Windows tricks. Available in English, Ukrainian and Russian.

**[⬇ Download WindowsToolbox.exe](https://github.com/barnibeats/windows-toolbox-releases/releases/latest/download/WindowsToolbox.exe)** — portable, no installation. Requires the WebView2 Runtime (built into Windows 11; for Windows 10 [get it from Microsoft](https://go.microsoft.com/fwlink/p/?LinkId=2124703)).

The app updates its catalog automatically on every launch and tells you when a new version of the app itself is out.
